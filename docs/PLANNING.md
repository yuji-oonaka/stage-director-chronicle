## 1. プロジェクト概要とコア体験（脳汁ポイント）

### 1.1 企画の思想
単なる「タイミングを合わせる音ゲー」ではない。役者のセリフ（キカケ）を耳で聴き、進行台本（プロンプト・スクリプト）をめくりながら、音響・照明・舞台機構のすべてを完璧な「一間（タメ）」でハメていく、**舞台監督・演出裏方職人の全能感**を味わうハイレゾリューション・シミュレーター。

### 1.2 コア体験（脳汁ポイント）
* **ト書きの体現**: 「セリフ終わりで即座に中割幕を閉鎖、10秒の暗転（タメ）を経てヒーローが迫り上がる」といった、脳内演出が完全に舞台上とシンクロする瞬間。
* **生々しいキカケの再現**: 実際の進行台本に書き込まれる「Rev↓（リバーブ下げる）」「Min?（照明変化）」「ドン由（緞帳自由）」といった現場の生きた暗号をシステムに昇華。
* **ミリ秒のシンクロ判定**: 指定時刻、あるいは指定セリフのジャストの瞬間からのズレを判定。±0.1秒以内の【PERFECT SYNC!】で舞台がバッ！とフラッシュする快感。

## 2. ゲームシステム＆画面構成（ノベルゲーム×舞台進行）

画面は「情報の即時 scannability（見やすさ）」を最優先した3分割のレスポンシブ・グリッドレイアウトを採用する。


```

+-----------------------------------------------------------------------+
|  [SeikoClock] 00:14:25.82  [STATUS] PERFORMANCE (Scene 1-2)           |
+-----------------------------------+-----------------------------------+
|                                   |  [StageMonitor]                   |
|  [PromptScriptArea]               |  +-----------------------------+  |
|  (左：台本・ト書き表示)           |  | 2D舞台ビュー（レイヤー構造） |  |
|                                   |  |                             |  |
|  聖女「星の導きよ、どうか……」     |  |   [緞帳] [中割幕] [役者]    |  |
|                                   |  +-----------------------------+  |
|  ※ト書き:                          +-----------------------------------+
|  セリフ終わりで中割幕【閉】       |  [OperatorConsole]                |
|  10秒のタメの後、小迫り【昇】     |  (右下：三研工業風・機構操作盤)   |
|                                   |                                   |
|                                   |  [中割幕:開/閉/S] [小迫り:昇/降/S]|
+-----------------------------------+-----------------------------------+

```

### 2.1 各エリアの責務
* **PromptScriptArea（台本エリア）**: ノベルゲームのように役者のセリフがリアルタイムにストリーミング（ハイライト）表示され、次に叩くべきキューの指示（ト書き）がスクロール表示される。
* **StageMonitor（舞台モニター）**: CSSのz-index（緞帳 → 中割幕 → 役者・小迫り → 蓄光マーク → ホリゾント）を活用した2Dパースビュー。
* **OperatorConsole（操作盤）**: プレイヤーが実際にクリック（またはキーバインド）でキューを叩く物理インターフェース。

## 5. 技術スタック＆アーキテクチャ方針

大掛かりなサーバーを一切立てず、ブラウザの標準APIを極限まで使い倒すことで「0円・爆速・高パフォーマンス」のフロントエンド完結型システムを構築する。

* **精密タイマーの駆動**: `requestAnimationFrame`（rAF）による単一ループを `TheaterMaster` に実装。ピュアな経過時間（ミリ秒）のみを宣言的に子コンポーネントへ流す。
* **セリフの自動音声化**: **Web Speech API（音声合成）** を採用。JSON内のテキストをブラウザが自動で発声し、役者のセリフの「ゆらぎ」と「キカケ」を完全再現。
* **音響システム**: **Web Audio API** を利用したカスタムフェーダーロジック。台本指示にある「Rev↓（リバーブ減衰）」やフェーダーによるボリュームフェードをピュアJavaScriptで制御。
* **途中セーブ・中断機能**: **`localStorage`** の活用。
* シーン切り替え時の「オートセーブ」、および幕間（15分）での「手動セーブ」を実行。
* 保存データ：`{ sceneId, elapsedTime, curtainState, seriPosition, score }`
* ロード時、保存されたStateからCSS transitionを一瞬で復元し、カウントダウン後に精密タイマーを再開。


* **拡張性（File API）**: 将来的に、ユーザーが自作した `script.json` と音源（MP3）をブラウザへドラッグ＆ドロップするだけで、サーバーなしで独自演目をプレイできるサンドボックス設計を担保。
